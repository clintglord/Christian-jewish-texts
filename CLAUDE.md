# Christian-Jewish Texts — Project Memory

## What this is
Next.js app with Prisma for ingesting, storing, and serving Christian and Jewish source texts. Includes a QA pipeline for Stage 1 review.

## Stack
- Next.js (TypeScript)
- Prisma ORM
- Source text ingestion scripts in `scripts/`
- QA tooling in `qa/`
